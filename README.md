# duifene-auto-rs · 对分易自动签到

Rust 编写的对分易（duifene.com）课堂签到助手，提供桌面 GUI 与命令行 daemon 两种形态。

## 功能

- **四种签到类型全覆盖**：二维码、数字码、汉字（九宫格点选）、定位（支持配置坐标与自动三角定位）
- **监听即 1 秒高频**：开始监听后每秒轮询全部课程，发现签到立即处理，直到手动停止、登录失效或退出程序
- **数字/汉字码自动补签**：平台升级后学生端接口不再下发签到码，本项目在签到结束的瞬间从教师端考勤列表取码并立即提交（服务端在结束后数秒内仍记出勤），全程无需手动输码
- **签到人数门槛**：可设全局百分比（0 为不限制），已签人数达标后才自动签到，避免当"第一个签到的"
- **微信 OAuth 登录**：无需账号密码，手机微信授权一次即可

## GUI 使用

1. 从 [Releases](../../releases) 下载 Windows 版（推送 `v*` 标签后 CI 自动构建），或自行编译：`cargo build --release -p duifene-gui`
2. 启动后点击登录：复制弹出的微信授权链接 → 手机微信打开并授权 → 把跳转后的完整地址粘回输入框
3. 点击开始监听，挂机即可；活动与事件看板实时显示发现、签到结果与失败原因

## daemon 使用（服务器 / 无界面）

`dfe` 命令行支持 `login / courses / schedule / coords / percent / mail / daemon` 等子命令，可按课程、按时段配置高频轮询窗口与 SMTP 邮件通知，配合 systemd 常驻运行。完整部署说明见 [DEPLOY.md](DEPLOY.md)。

## 开发

```bash
cargo test --workspace        # 测试
cargo build --release         # 构建
```

工作区包含 `duifene-core`（引擎、API 客户端、dfe CLI）与 `duifene-gui`（Slint 桌面界面）。
